# QuantumTrace interface

QuantumTrace is a local security analysis tool for developers and security engineers,
including a live hackathon demonstration. It has no account or subscription model.

Preserve the imported Lovable identity: cream surfaces, dark sidebar, restrained gold
accents and clean typography. `frontend/src/styles.css` owns runtime theme tokens;
reuse `components/ui/button.tsx` and `components/ui/dialog.tsx` for actions and overlays.
Do not introduce an independent palette or replace the existing workspace shell.

The README describes data loading and retention. `ReportProvider` owns the current
report and asynchronous operations; `ScanDialog` owns upload selection and validation
feedback. Scan failures keep the previous report. Pending scans show an honest phase,
not an invented percentage. Successful scans reset inventory filters so new findings
are immediately visible. Backend scores and classifications remain authoritative.

Label bundled examples as demo/sample data. Distinguish upload results from saved CLI
results. Use filename, size and explanatory text alongside validation colors. Keep
dialogs keyboard accessible and scrollable within small viewports, with visible focus
and inline retry guidance. Verify selection, progress, success, failure and exports
through the production server as well as component tests.
